# ЛР6 Сравнение локальных и облачных LLM

Учебный помощник аналитика ИБ: сравнение локальной `google/gemma-3n-e4b` и облачной `GigaChat-2` (фактическая версия `GigaChat-2:2.0.30.01`). Выполнены **60 реальных запросов**, по 30 каждой модели, 23–24 октября 2026 по Омску. 20 одинаковых заданий шести типов; пять заданий повторены по три раза. Первые десять промптов взяты без изменений из ЛР1/ЛР5.

Средняя оценка сначала усредняет повторы одного задания, затем 20 заданий с одинаковым весом. По всем 30 вызовам оценка обеих моделей — 1,367, полный успех 40% и 36,7%. Оценку открытых ответов выполнил ИИ-ассистент, не независимый человек. Формат, точные метки и чистые функции Python проверены отдельно. Все ответы `finish_reason=stop`.

GigaChat израсходовал 3902 токена из доступного бесплатного пакета; уменьшение баланса совпало с API usage. Для 1000 и 100000 аналогичных запросов расчёт составляет 130067 и 13006667 токенов: 0 руб. в пределах наблюдавшегося Freemium и срока его действия. Иллюстративный расчёт по старому платному пакету существующих клиентов и ограничения приведены в отчёте. Покупок не выполнялось.

## Запуск в PyCharm 2025

Рабочая папка — `lab_06`, Python 3.12. В терминале Windows:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
python src/setup_ca.py
```

В `.env` локально заполните `GIGACHAT_AUTH_KEY` своим Authorization Key и проверьте `GIGACHAT_SCOPE=GIGACHAT_API_PERS`. Скрипт читает `.env` сам; заданные переменные окружения имеют приоритет. Не отправляйте файл другим пользователям и не добавляйте в Git. `setup_ca.py` скачивает открытый корневой сертификат по официальной HTTPS-ссылке, сверяет SHA256, сохраняет в игнорируемый `certs/`. Проверка TLS и hostname включена; хранилище доверия ОС не меняется. При изменении сертификата сначала проверьте его по официальной документации.

Для локального повторения загрузите Gemma 3n E4B Q4_K_M в LM Studio, контекст 8192, сервер на 127.0.0.1:1234. Облачный прогон не требует работающей локальной модели.

```bat
python src/benchmark.py --backend local
python src/benchmark.py --backend cloud
```

Каждый запуск создаёт новый каталог; API-ошибка облака останавливает цикл без автоматических повторов. Используется фиксированная GigaChat-2 и личный доступ, до генераций проверяются модель и остаток токенов. Программа не покупает пакеты. Числа temperature=0.2, max_tokens=650, stream=False и messages одинаковы.

Для пересчёта **опубликованного** эксперимента без API:

```bat
python src/metrics.py
python -m pip install -r requirements-report.txt
python src/build_report.py
```

`metrics.py` проверяет SHA256 ответов, соответствие всех 30 пар промптов/параметров и строит CSV/JSON/PNG. Для нового прогона нужны новые оценки с хешами и обновление `RUNS`; старые баллы автоматически не переносятся. `requirements-lock.txt` фиксирует окружение измерений/графиков. Word создаётся из сохранённых метрик, без API.

## Выводы и ограничения

Облако быстрее в наблюдавшихся условиях, но длины ответов и фоновые нагрузки отличаются. Локально RAM в среднем 26,44 GiB из 27,29 GiB, GPU 92,9%; счётчики включают другие программы. Для облака измерен компьютер клиента, не сервер поставщика. TTFT и чистая скорость декодирования не измерялись, токенизаторы различаются, параллельная нагрузка не тестировалась. Не следует объявлять отношение задержек универсальной разницей архитектур.

Обе модели пропускают обязательный отзыв опубликованного токена и принимают некорректные длинные последовательности октетов как содержащие IPv4. JSON требует отдельной валидации. Детальные пограничные проверки добавлены после чтения ответов; основные критерии заданий и рубрика существовали до запусков. Нужна независимая проверка перед практическим применением.

Внутренние документы — локальный контур; публичные обезличенные запросы — облако при допустимых условиях; смешанные заявки — гибридная маршрутизация независимым программным слоем. Чувствительный запрос нельзя автоматически отправлять в облако как резервный путь. Только синтетические учебные данные, ключи исключены из Git. Визуальная проверка страниц Word пропущена по просьбе пользователя.
