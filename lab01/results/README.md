# Результаты

`report.md` содержит предоставленный отчёт с таблицами и выводами, преобразованный из Word. `report_table_*.csv` — таблицы из отчёта, а не сырые API-ответы.

Остальные CSV и JSON — исходные результаты запусков 16.09.2026, скопированные из проекта автора без изменения. Совпадение числа записей и полных ответов между CSV и JSON проверено. Новые запросы к моделям при оформлении не выполнялись.

В корне этой папки находятся три итоговых прогона по 10 ответов. В `preliminary/` сохранён ранний прогон Qwen с восемью пустыми ответами; он не включён в итоговые средние. Числовые оценки качества находятся в отчёте: пустые поля оценок исходного экспорта не заполнялись задним числом.
