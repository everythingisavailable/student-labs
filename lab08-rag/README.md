# ЛР8 Построение RAG системы

Вопрос → эмбеддинг → разрешённые фрагменты NumPy-индекса ЛР7 → контекст с [S#] → локальная Gemma → ответ и аудит ссылок. 40 фрагментов из пяти учебных документов. 16 вопросов: 5 прямых, 4 перефразированных, 3 по двум источникам и 4 без ответа; 48 реальных генераций при k=2/4/8.

## Запуск в PyCharm 2025

Выберите Python 3.12 и виртуальное окружение. Рабочая папка команд — `lab08-rag`. В LM Studio загрузите `google/gemma-3n-e4b` и запустите сервер на порту 1234.

```sh
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python src/rag.py "Как часто выполняют пробное восстановление копий?" --k 4
python src/evaluate.py
python src/test_pipeline.py
```

Эмбеддинги: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, revision `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`, 384 координаты, L2-нормализация, CPU. Матрица скопирована из ЛР7 без изменения; `src/ingest.py` может перестроить её. Max sequence length=512, без скрытого усечения. При первом запуске нужен интернет для весов; затем можно задать `HF_HUB_OFFLINE=1`. Для уже скачанной копии используйте `LAB7_MODEL_PATH`. Облачный API не нужен. LOCAL_BASE_URL допускает только loopback; LOCAL_API_KEY при необходимости задаётся переменной окружения. `.env` автоматически не читается.

Одиночный запрос по умолчанию имеет роль `students`, `--role admins` открывает весь учебный корпус. Эксперимент использует admins. Аргумент роли — демонстрация политики, не аутентификация.

## Параметры и результаты

Gemma GGUF Q4_K_M, контекст 8192, temperature=0.2, max_tokens=650, seed=42 передан серверу (детерминизм не проверен). Базовые абзацы ЛР7, без дополнительного перекрытия. Каждая пара вопрос/k вызвана один раз, порядок перемешан фиксированным seed; загрузка эмбеддингов не входит в задержку.

| k | Recall | MRR | Оценка из 10 | Корректный отказ % | Время с |
| --- | --- | --- | --- | --- | --- |
| 2 | 0.708 | 0.800 | 7.56 | 100 | 1.386 |
| 4 | 0.750 | 0.800 | 8.06 | 100 | 1.823 |
| 8 | 0.958 | 0.800 | 7.81 | 100 | 1.787 |

Recall и MRR рассчитаны по 12 ответимым вопросам. Полный MRR не зависит от k; MRR@k тоже сохранён. Оценка ответов выполнена ассистентом по явной рубрике и не является независимой человеческой оценкой. 100% отказов относится только к четырём отсутствующим фактам в каждой конфигурации.

Пример q01: запрос о периодичности проверки резервных копий возвращает `backup_02` как S1; ответ: «Пробное восстановление резервной копии выполняется раз в месяц на изолированной тестовой площадке [S1]». Полные исходные ответы сохранены без исправлений.

## Ограничения и безопасность

При k=8 полнота поиска выше, но оценка ответов хуже, чем k=4. q12 показывает пропуск части ответа при обоих найденных источниках; q08 — неподтверждённую ссылку при ошибке поиска. Существование [S#] не доказывает истинность утверждения. После опыта валидатор научен распознавать группы `[S1, S2]` и отмечать их как нестандартный формат; сырой прогон и исходный код сохранены.

Фильтр прав исключает закрытые тексты и метаданные до передачи LLM. 16 проверок students не вернули закрытых документов; тест конвейера проверяет фактический контекст. Внешние адреса/редиректы запрещены. Документы — данные, модель не получает инструментов; общая устойчивость к prompt injection не доказана. Векторы не являются шифрованием.

Личные данные в публичном отчёте отсутствуют. Визуальная проверка страниц пропущена по просьбе пользователя. ЛР6 выполнена отдельно в [lab_06](../lab_06/).
