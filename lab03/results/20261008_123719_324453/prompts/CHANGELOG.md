# Версии промпта
| Версия | Изменение | Цель | Экспериментальный результат |
| --- | --- | --- | --- |
| v1 | Краткий базовый запрос | Исходная точка | Ожидает прогона |
| v2 | Роль, классификация, ограничения и шесть полей | Проверить структурирование и осторожность | Ожидает прогона |
| v3 | Три отдельных примера: норма, аномалия, недостаток данных | Проверить few-shot на том же наборе | Ожидает прогона |
| v4_json | JSON вместо текстовых полей | Проверить пригодность для программной обработки | Ожидает прогона |

v3 — исходный кандидат few-shot, подготовленный до эксперимента. После анализа v1/v2 нужно документировать выявленные ошибки и при необходимости уточнить v3 и повторить серию. Улучшение не предполагается заранее.
