# Лабораторная работа №2

## Тема и цель

Параметры генерации и конфигурация LLM. Цель — выяснить, как системная инструкция, temperature и ограничение длины меняют ответ модели, и подобрать настройки для первичного анализа события информационной безопасности.

## Задачи

1. Получить базовые ответы.
2. Сравнить три системные инструкции на одном событии.
3. Выполнить по пять повторов для четырёх значений temperature.
4. Проверить три ограничения длины ответа.
5. Проверить практическую конфигурацию и сохранить результаты.

## Технологии и структура

Python, `openai`, `python-dotenv`, стандартные `csv`, `json`, `time`; LM Studio и локальная модель `google/gemma-3n-e4b`. Код: [src/lab02.py](src/lab02.py). Результаты: [results/](results/). Дата эксперимента в отчёте: 16.09.2026.

## Как устроено решение и почему

Функция `ask_model` собирает сообщения и добавляет `temperature` и `max_tokens` только при явном указании. Это позволяет сравнивать базовую конфигурацию с управляемыми настройками. Значения, не переданные API, зависят от настроек локального сервера, поэтому для строгого повторения нужно также сохранить настройки LM Studio.

Изменяется один исследуемый фактор за раз. Повторы при разных temperature нужны для оценки вариативности. Сохраняются ответ, задержка, причина завершения, токены, параметры и ошибка. CSV удобен для анализа, JSON — для просмотра полных ответов. В базовой серии поле `system_prompt` исходной программы остаётся пустым, хотя фактически применяется строка по умолчанию «Отвечай точно и по существу.»; при интерпретации экспорта это необходимо учитывать.

## Запуск

Нужны Python 3.10+ и работающий локальный сервер LM Studio по адресу `http://localhost:1234/v1`. Загрузите нужную модель и проверьте её точный идентификатор на сервере. Экспериментальные названия моделей взяты из отчёта; доступность конкретных сборок отдельно не проверялась.

Из корня репозитория в терминале PyCharm (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r lab02/requirements.txt
Copy-Item lab02/.env.example lab02/.env
```

В `lab02/.env` заполните `LLM_API_KEY`, `LLM_BASE_URL` и `LLM_MODEL`. Если локальная аутентификация LM Studio отключена, для требования SDK к непустому ключу можно использовать условное значение `lm-studio`; при включённой аутентификации нужен действующий локальный токен. `.env` не загружается в Git.

```powershell
cd lab02
..\.venv\Scripts\python.exe src/lab02.py
```

Рабочий каталог должен быть `lab02`, чтобы результаты сохранились в `lab02/results/`. Для запуска зелёной кнопкой PyCharm выберите интерпретатор `.venv` и в конфигурации запуска задайте тот же рабочий каталог.

Зависимости указаны диапазонами совместимости; точные версии исходной экспериментальной среды в отчёте не зафиксированы. Повторные ответы и задержки могут отличаться.

Один запуск выполняет 30 вызовов: 3 базовых + 3 системные инструкции + 20 повторов temperature + 3 лимита длины + 1 практическая конфигурация.

## Вывод

Системная инструкция влияет на структуру и объём, но не гарантирует отсутствие домыслов. Низкая temperature лучше подходит для воспроизводимого аналитического ответа, повышенная — для разнообразия идей. Ограничение длины необходимо подбирать под задачу: даже 800 токенов оказалось недостаточно для подробного разбора RAG, а 400 хватило для краткого анализа события ИБ. Выводы относятся к одной модели и ограниченному набору запросов.
