# Паспорт тестового набора

30 новых синтетических событий: 10 easy, 10 hard, 10 boundary. Классы сбалансированы: 15 normal и 15 suspicious. Индивидуальное задание — первичная классификация ИБ-событий; этот же набор выполняет основную и индивидуальную части.

Используются БЕЗ ИЗМЕНЕНИЙ prompt_v2.txt (A) и prompt_v4_json.txt (B) из ЛР3. Их происхождение и SHA256 зафиксированы в ../prompts/provenance.json. A возвращает шесть текстовых полей, B — JSON с шестью полями. Это существенно различающиеся конфигурации одной модели: B содержит few-shot и уточнения ЛР3. Дополнительных системных правил, порогов или новых промптов классификатора нет.

category=normal преобразуется в normal; authentication_anomaly/phishing/malware/data_exposure — в suspicious; unknown — в abstain. Отказы и ошибки разбора не исключаются. Accuracy считается на всех 30; Recall учитывает пропущенные положительные случаи из abstain/parse_error. Матрица имеет две строки эталонов и четыре столбца результатов. Format compliance проверяется по собственному контракту A/B; отдельно фиксируется JSON compliance.

Эталоны, F1 положительного класса как основная метрика, 10 пар для проверки и 5 сложных примеров для трех дополнительных повторов зафиксированы до запросов. Ни один вход не скопирован из примеров few-shot ЛР3; темы неизбежно близки. Это небольшой авторский набор, а не внешний независимый бенчмарк. Промпты не меняются после просмотра ответов. Для всех 30 входов есть данные для эталонной категории; недостающие сведения об ущербе не разрешают его выдумывать.
