# ЛР5. Локальные LLM

Одна модель: google/gemma-3n-e4b, GGUF Q4_K_M, LM Studio 0.4.24.0. Выполнено 25 реальных запросов без ошибок. ЛР6 отложена.

## Запуск в PyCharm 2025

Откройте репозиторий, выберите Python 3.11+ и виртуальное окружение. В терминале перейдите в `lab05-local-llm`. В LM Studio запустите сервер на localhost:1234 с указанной моделью.

```sh
python -m pip install -r requirements.txt
python src/client.py --interactive
python src/client.py --experiment
python src/client.py --prototype
```

В интерактивном режиме `/exit` завершает диалог; каждый запрос независим. Для прототипа с вводом: `python src/client.py --prototype --interactive`. В Run Configuration укажите script `src/client.py` и нужный параметр. LOCAL_BASE_URL и LOCAL_API_KEY при необходимости задаются в Environment variables; `.env` автоматически не читается. Ключ не публикуйте.

Эксперимент выгружает и загружает только выбранную модель, чтобы измерить показатели до/после загрузки. Затем выполняет 5 повторов, 5 исходных запросов ЛР1, 5 заданий методички, 9 творческих ответов на промпт ЛР2 и 1 прототип с промптом ЛР3. Параметры — `config.json`; исходные тексты — `data/` и `prompts/`.
