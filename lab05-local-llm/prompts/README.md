# Происхождение промптов

Общая системная инструкция перенесена из ЛР1 без изменения текста. В previous_prompts.json сохранены пять исходных пользовательских запросов ЛР1; удалены только внешние пробелы, как в исходном клиенте. Творческий запрос и его system prompt взяты из ЛР2 без изменений. Промпт индивидуального прототипа — исходный prompt_v4_json ЛР3.

Пять дополнительных M1–M5 следуют новому обязательному набору методички ЛР5. Они сохранены отдельно и не подменяют исходные промпты. Метрики сравнения разных типов запросов не смешиваются с пятью повторениями одного запроса.
