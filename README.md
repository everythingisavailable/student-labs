## Организация

В каждой лабораторной `src/` содержит программу, `results/` — отчёт и результаты, `requirements.txt` — зависимости, `.env.example` — пример подключения без ключа. Отдельный README объясняет задачу, решения, эксперименты и запуск.

Эксперименты выполнены локально через LM Studio. Установка Python-зависимостей не устанавливает модели: их необходимо отдельно загрузить и запустить в LM Studio. Используются синтетические учебные события ИБ.

Работать с репозиторием можно в PyCharm 2025. Команды установки и запуска приведены в описании каждой лабораторной. Ключи и локальные настройки `.env`, `.idea` и виртуальное окружение не публикуются.
