## Организация

В каждой лабораторной `src/` содержит программу, `results/` — отчёт и результаты, `requirements.txt` — зависимости, `.env.example` — пример подключения без ключа. Отдельный README объясняет задачу, решения, эксперименты и запуск.

Локальная генерация выполняется через LM Studio; в ЛР6 дополнительно использован облачный GigaChat API, в ЛР7 — локальная модель эмбеддингов. Установка Python-зависимостей не устанавливает модели: их необходимо отдельно загрузить и запустить в LM Studio. Используются синтетические учебные события ИБ.

Работать с репозиторием можно в PyCharm 2025. Команды установки и запуска приведены в описании каждой лабораторной. Ключи и локальные настройки `.env`, `.idea` и виртуальное окружение не публикуются.

В ЛР9–ЛР11 публичные отчёты находятся в `report/report.md`; личные Word-копии для преподавателя хранятся отдельно. Содержательные оценки ответов сделаны ИИ-ассистентом и отделены от автоматических тестов программы. Ошибки моделей сохранены и разобраны.
