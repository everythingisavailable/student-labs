Основная серия — runs.jsonl; модель — generation_model.json; исходный код основной серии — source_snapshot и execution_source_sha256.json. pre_run_sha256.json — историческая фиксация первоначального плана до пилотов, а не хеш итоговой версии. Пилоты хранят собственные исходные запросы и ответы; они исключены из metrics.json. quality_review.json — отдельная оценка ИИ-ассистента; исходный ответ не редактируется.
